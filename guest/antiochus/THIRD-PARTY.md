# Antiochus graphics conformance fork — source notices

Piglit snapshot 62ef6b0db (2018-05-15), including the piglit C ports of glean. Mesa demos 8.4.0. The catalogue maps every case to its original file. These are reduced ports to CGL, not the full upstream cases. The download variants add glGetTexImage to the written FBO texture. The two GLSL probes and Core Image chain are original Antiochus cases.

The glean logicop port credits Brian Paul and Laura Ekstrand. The combine test credits Brian Paul and Gareth Hughes.

Source archives: https://archive.debian.org/debian/pool/main/p/piglit/piglit_0~git20180515-62ef6b0db.orig.tar.xz and https://archive.mesa3d.org/demos/mesa-demos-8.4.0.tar.bz2


## Fork and scope

Antiochus graphics conformance is a downstream fork of selected Piglit, glean and mesa-demos tests. Its CGL/Cocoa runner and Core Image cases belong to Antiochus. The CPU benchmark and Rosetta Stone are separate. Upstream did not certify this fork.

The shader profile imports executable portions of 338 static .shader_test files from tests/spec/{glsl-1.10,glsl-1.20,arb_vertex_program,arb_fragment_program} at Piglit 62ef6b0db. Each executable catalogue row records the original path and original file SHA-256. tests/import-shader-fork.py reproduces the compiled catalogue from the exact archive. Five historical crash/hang regression fixtures are outside this functional profile. Generated suites and other directories are outside this catalogue.

The same snapshot is the source of tests/shaders/shader_runner.c and tests/util/piglit-util-gl.c (runner semantics, drawing, texture fixtures and probes). The fork preserves the script assertions and 0.01 normalized channel tolerance. It uses Apple CGL, a visible window, separate software/accelerated verdicts, exact driver logs and a two-sided report. The two uppercase GL_ARB_DRAW_BUFFERS requirements are normalized to GL_ARB_draw_buffers. The passthrough shader uses the compatibility-profile branch. An extra alpha value after an RGB probe is ignored as in the upstream scanner.

The snapshot COPYING describes a preferred license, with file-specific exceptions. Debian 0~git20180515-62ef6b0db-1 tags the general file set MIT. The selected shader directories do not match its exception paths. The Khronos notice in fs-array-deref-then-write.shader_test is reproduced below. Individual notices take precedence. Debian source licensing inventory: https://archive.debian.org/debian/pool/main/p/piglit/piglit_0~git20180515-62ef6b0db-1.debian.tar.xz
