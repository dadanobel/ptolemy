# Antiochus draft 4 / Rosetta Stone

[исх.] Два приложения PowerPC для Tiger/Leopard. **Antiochus** запускает 34 CPU/GPU-случая и отдельный Classic, показывает CPU/GPU/Overall, сохраняет подробный пакет на Desktop. **Rosetta Stone** открывает вращающийся трёхмерный камень: изменяемый размер окна, текущий FPS, самостоятельная иконка. Закрытие — кнопкой окна или Escape. Свободный режим не создаёт баллов и отчётов.

[изм.] Пять новых сцен прошли в Tiger 10.4.11 и Leopard 10.5.8; самостоятельное окно и установка проверены в обеих ОС. Прежние geometry/scene и основной Leopard branch остаются fail. Это draft с указанными в отчёте ограничениями.

[исх.] В draft 4 добавлены пять тематических экранных сцен: камень → истоки Панея → фаланги → конница → массовая битва при Панионе. Финальная сцена включает 4312 агентов, движение на CPU и около 612 тысяч треугольников на кадр. Все модели, текстуры и иконка камня оригинальные. Бенчмарк не читает настройки Ptolemy и не имеет исключений по имени эмулятора.

[оценка] Открыть приложение из ZIP либо установить Tools в гостевой ОС. Для сравнения запустить Antiochus, оставить тестовое окно видимым и убрать курсор с рисунка. Не менять разрешение, состояние ОС и конфигурацию между сравниваемыми прогонами. Свободный FPS камня при разных размерах окна — наблюдение, а не сопоставимый балл.

[исх.] Общие оценки score-3 и score-4 несовместимы. Старые 29 задач сохранены, их времена можно исследовать отдельно; новый набор получает собственную исходную серию A/A и ABBA. `compare.py` не разрешает ранжировать разные версии.

## Воспроизведение сборки

[исх.] Базовая сборка — внутри Tiger, Apple GCC 4.0.0 / SDK 10.4.0. Компилятор и SDK не входят в поставку. Только прежний `vmx.c` собирается для AltiVec; остальные файлы для G3. Подтест Classic перенесён без изменения из draft 3; его SHA-256 указан в проверке сборки.

```sh
CC=/path/to/devkit/bin/ppc-cc sh tests/check.sh
ANT_CLASSIC_BIN=build/classic/AntiochusClassic.bin \
  PT_TIGER_CC=/path/to/devkit/bin/ppc-cc sh build-tiger.sh
```

[исх.] Исходники Classic и закреплённый способ его сборки — `classic/` и `build-classic.sh`. Он выполняется в Classic на Tiger; Leopard получает `unsupported_os`. Это конкретные CRC/QuickDraw-задачи, не полное покрытие Classic 3D.

[неизв.] Проверки в Ptolemy и на GPU хоста не заменяют калибровку настоящих G3/G4 и R300/R500. Даже успешный прогон не доказывает совместимость всех игр или отсутствие каждого промежуточного артефакта. Точные результаты приведены в проверке сборки.
