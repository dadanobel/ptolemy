# Artwork

| File | Use |
|---|---|
| `app-icon-macos-1024.png` | The app icon (built into `Ptolemy.icns` by `tools/build-product.sh`) |
| `app-icon-256.png` | The icon at 256 px, for pages |
| `github-social-1280x640.jpg` | The README header and the repository's social preview |
| `metal-banner.jpg` | The README's graphics section: the mark from the header with text set in Inter (SIL Open Font License) |
| `mark-transparent-1024.png` | The mark alone, with transparency |
| `launcher-metal.jpg`, `mark-glass.png` | The launcher's brushed metal and glass mark, made by `launcher-art.py` |
| `tile-tiger.png`, `tile-leopard.png` | The list's tiles: each system's fur in a metal bezel, made by `launcher-art.py` |
| `launcher-fur.jpg`, `launcher-leopard.jpg` | The procedural fur the tiles are cut from, made by `launcher-art.py` |

The mark shows a Ptolemaic king's profile on a stone shaped after the Rosetta Stone. The images were generated for
Ptolemy with an image model and are licensed with the project (GPL-2.0-or-later).

The launcher's art is drawn by `launcher-art.py` from random numbers alone: no artwork of Mac OS X or of Apple is used
or imitated pixel for pixel - no logo, no fur "X", no box, no desktop picture, no system icon.
